# Compiling

Os comandos seguintes devem ser executados a partir da pasta `E1-TCP01`.

## Server

```text
cd tcp01-servidor
javac tcp01\Person.java tcp01\Place.java tcp01\TCPServer.java tcp01\Connection.java
```

## Client

```text
cd tcp01-cliente
javac tcp01\Person.java tcp01\Place.java tcp01\TCPClient.java
```
